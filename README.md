# 华鑫邮件整理 Skill

本仓库只分享一个 Codex Skill：`huaxin-mail-organizer/`。它与作者的个人 Skills 私有仓库分开；不会公开那个仓库或其中的其他 Skills。

## 安装

1. 在 GitHub 页面点 **Code → Download ZIP** 并解压。
2. 把解压后仓库中的整个 `huaxin-mail-organizer` 子文件夹复制到个人目录 `~/.codex/skills/`；不要复制外层仓库文件夹，也不要只拿 `SKILL.md`。项目内使用则放到项目的 `.agents/skills/`。
3. 在 Codex 新开一个任务检查 Skill 是否出现；若未出现，再重启 Codex。

在 macOS Finder 中可用“前往文件夹…”打开 `~/.codex/skills/`。详细安装说明和名称同步工具见 [Skill 内的 README](huaxin-mail-organizer/README.md)。

## 使用条件

邮箱操作依赖 Codex 内置浏览器和 Computer Use。使用者自行登录和完成验证；本仓库不含密码、验证码、邮箱会话或邮件附件。
